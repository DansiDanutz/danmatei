# api/news

## Overview
Lets an owner draft a weekly news post. The draft is generated by an LLM from the last 7 days of activity: training recaps, match results and new families. Nothing is saved.

## Interface
- **`POST /api/news/draft-weekly`** (`draft-weekly.ts:handler`): bearer JWT. It reads no body or query parameters.
  - Returns 200 `{ok:true, title, body_md, fallback, sources:{recaps, matches, newFamilies}}`.
  - When the fallback is used, the response also includes `warning`: `ai_not_configured`, `ai_generation_failed` or `ai_parse_failed`. With `ai_generation_failed` it also includes `detail` with the error message.
  - Errors: 401 `missing_bearer`, `invalid_jwt` or `no_profile`; 403 `owner_role_required`; 405 `method_not_allowed`; 429 `rate_limited`, with a `Retry-After` header; 503 `supabase_unavailable`.
- Internal helpers (not exported): `fallbackDraft`, `parseDraftJson`, `isoDaysAgo`, `firstName`, `roDate`, `compactText`, `normalizeMatchResult`. [draft-weekly.ts]

## Invariants
- **Access:** only `owner` or `super_admin` can call it. [draft-weekly.ts:handler]
- **Always a draft:** the endpoint always returns a usable draft. If AI is unavailable, fails, or returns output that cannot be parsed, it returns a deterministic `fallbackDraft`. [draft-weekly.ts:fallbackDraft, handler]
- **Rate limit:** 20 per hour per user (`draft-weekly:${userId}`). It is checked only when OpenAI is configured. [draft-weekly.ts:handler]
- **Privacy:** only the first names of new children, each with its `age_group_label`, are sent to the LLM. The prompt splits `full_name` inline; `firstName` is used only by `fallbackDraft`. [draft-weekly.ts:handler, fallbackDraft]

## Side Effects
- **Database reads only:**
  - `fotbal.schedule_events`: up to 15 recent trainings that have a `recap_md`, and up to 10 recent matches with embedded `match_results` (matches are included whether or not they have a result)
  - `fotbal.children`: up to 20 created in the last 7 days, status `active`
- **LLM call:** `generateText` with maxTokens 900 and temperature 0.5. Env: `OPENAI_API_KEY`, `OPENAI_BASE_URL`, `OPENAI_MODEL`.
- **Rate limit state:** updates the in-memory counter.
